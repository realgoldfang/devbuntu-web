Devbuntu

Development packages for Ubuntu

Getting Started

Add the Devbuntu repository to your system to install development packages. Packages not found here will automatically fall back to Ubuntu's official repositories.

How It Works

Devbuntu is a supplementary repository. APT searches all configured sources when installing packages — if a package exists in both Devbuntu and Ubuntu repos, Devbuntu's version takes priority.

Installation

1. Import the GPG Key

curl -fsSL https://realgoldfang.github.io/devbuntu-web/gpg-key.asc | sudo gpg --dearmor -o /usr/share/keyrings/devbuntu-archive-keyring.gpg

2. Add the Repository

echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/devbuntu-archive-keyring.gpg] https://realgoldfang.github.io/devbuntu-web stable main" | sudo tee /etc/apt/sources.list.d/devbuntu.list > /dev/null

3. Update Package List

sudo apt update

4. Install Packages

sudo apt install <package-name>
